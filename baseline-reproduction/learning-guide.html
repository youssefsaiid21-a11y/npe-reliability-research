Our thesis / a simple explanation

Follow our code,
one file at a time.

Our command calls a coordinator. The coordinator runs the authors’ model code. That code produces known parameters and their matching time series.

Start with these three files

Read them in execution order. We can leave the older network experiments until later.

1. thesis — starts Python

This is our small launcher. It finds the project’s tested Python environment and starts thesis_cli.py. It contains no model equations.

2. thesis_cli.py — chooses the action

This file reads words such as generate, RW and 16. Its main() function routes the command. For generate, it calls the coordinator. For learn, it opens this guide.

from run_author_generator import main as generate

# We call the coordinator when we choose "generate".
output = generate([...])

This is a shortened example of the command flow. The name generate refers to the coordinator’s main() function.

3. run_author_generator.py — coordinates one run

Start at its main() function near the bottom. We can read the flow as four steps:

  1. verify_source() checks the original files.
  2. run_generator() launches the authors’ simulator.
  3. validate_outputs() checks each parameter/data pair.
  4. write_json() records the run and its checks.

The longer helper functions above main() implement those checks. We do not need their details to understand the flow.

Then: the authors’ script and model equations

The coordinator calls the authors’ synth_data_gen_pysdtorch.py. That script chooses parameters, runs the model and saves accepted datasets. The model’s .mdl file contains the actual stocks, flows, constants and noise equations. Their pysdtorch/ engine executes those equations over time.

For Random Walk, State is the accumulating quantity and StateChng is its rate of change. The starting value initializes the state; drift and process noise affect its change.

The guide files — display only

learning_guide.py reads a few checked examples. learning-guide.html displays this page and draws the graphs. Neither runs NPE or changes the experiment.

What does “one dataset” mean?

One set of known parameters and one matching time series. A dataset may contain several observed series: for example, SEIRb produces onset, recovery and death-rate series.

To evaluate NPE, we repeat the process over many datasets. NPE receives the numerical time-series values with its required preprocessing; the graph here is a drawing of those numbers. We keep the known parameter values separately to check its answers.

The command we use to start

In the project’s terminal:

./thesis generate --model RW --cases 16

This generates 16 Random Walk datasets and their known parameters. Change RW to SEIRb or GB for the other models.

./thesis status        # see what is ready
./thesis show          # read one Random Walk example
./thesis files         # explain the file execution order
./thesis learn         # open this explanation

Switching examples on this page displays saved data; it does not run another simulation. The command above runs the model and saves a new experiment.

After the baseline works

We change one assumption in the model, generate new data, and give that data to the same fixed NPE. We then measure how its answers and uncertainty change.

Why can’t we use the older GitHub networks?

We have not established that they correspond to our manuscript. We found differences in the model configuration and data format. Using them automatically would mix versions and would not establish reproduction of our paper.

What is a pretrained network?

A saved file containing what NPE has already learned. We load it and use it. We do not teach it again.

Why do generated graphs change?

Changing parameters changes the model’s behavior. Random noise can also produce different graphs with the same parameters. A random seed makes a particular run repeatable.

Do we need the convolution or LSTM details now?

No. Those are internal parts of NPE. First understand how we generate paired parameters and time series, then how we compare NPE’s estimates with the known answers.
